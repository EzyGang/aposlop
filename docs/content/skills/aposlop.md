# `aposlop`

Use this skill to install, configure, run, and read Aposlop.
It also helps add Aposlop to CI and agent checks.

## When to use it

Use it for duplicate code, large files, high complexity, configuration, or Aposlop findings.
The skill starts automatically when the request matches these tasks.
