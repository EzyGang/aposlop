# `aposlop-code-changes`

Use this skill to make the smallest complete code change.
It first checks whether existing code or a standard tool already solves the problem.

## When to use it

Use it for implementation, bug fixes, refactoring, maintenance, or Aposlop findings.
The skill starts automatically for these changes.

## Example

```text
Fix this bug at its shared source and keep the change small.
```
