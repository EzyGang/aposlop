# `aposlop-deslop-turbo`

Use this skill for a full test and production code cleanup.
It removes weak tests first, then reduces code without changing behavior.

## When to use it

Start this skill manually when a broad cleanup is wanted.
Give it a file, directory, or repository scope.

```text
/aposlop-deslop-turbo src
```

Select `aposlop-deslop-turbo` by name when slash commands are unavailable.
