# `aposlop-deslop-tests`

Use this skill to remove tests that protect no distinct behavior.
It can also remove production code that existed only for those tests.

## When to use it

Start this skill manually for test cleanup.
Give it a file, directory, or repository scope.

```text
/aposlop-deslop-tests src/tests
```

Select `aposlop-deslop-tests` by name when slash commands are unavailable.
