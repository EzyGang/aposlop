# AI Usage Policy

Aposlop permits AI tools in contributions.

## Allowed use

You can use AI tools for:

- Code research
- Implementation assistance
- Test generation
- Documentation assistance
- Refactoring suggestions
- Debugging assistance

You remain responsible for every submitted change.
Review generated code before you submit it.
Verify behavior with the project checks.
Do not submit code that you do not understand.

## Human-written descriptions

A human must write every pull request description.
A human must write every issue description.

Do not use AI to draft, rewrite, expand, summarize, or translate these descriptions.
Describe the problem and your work in your own words.

This rule lets reviewers evaluate the contributor's understanding and intent.

## Disclosure

Disclose material AI assistance in the pull request checklist.
Name the tool when it produced or substantially changed submitted code.
Minor completion suggestions do not require a detailed usage log.

## Review responsibility

AI assistance does not reduce the required review standard.
Contributors must answer review questions without generated explanations that hide their understanding.
Maintainers can close submissions that do not follow this policy.
